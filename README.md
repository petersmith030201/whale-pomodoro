# 肥鱼专注屋 · Whale Focus

一个以 Q 版大肥鱼鲸鱼娘为主题的中文番茄钟。游客打开即可使用，支持任意层级任务树、本地保存，以及完整 JSON 备份的导入和导出。

本项目为非官方社区主题创作，与深度求索公司或 DeepSeek 官方无关联。角色参考与生成过程见 [ATTRIBUTION.md](./ATTRIBUTION.md) 和 [ASSET_NOTES.md](./ASSET_NOTES.md)。

## 功能

- 默认专注 25 分钟、短休息 5 分钟、长休息 15 分钟；每完成 4 个番茄后长休息，时长和轮次可调整。
- 开始、暂停、继续、重置和跳过休息；自动开始休息、自动开始专注分别设置，默认关闭。
- 任务可以不断添加子任务，支持折叠、搜索、完成、调整父级和顺序，以及聚焦某棵子树。软件不预设固定层级上限，实际容量取决于浏览器和设备。
- 开始一轮时绑定任务，暂停后继续保持原任务归属；完整结束才增加番茄数，已经投入的实际专注时间也会保存。
- 统计今日专注时间、完成番茄和任务进度，并查看专注记录。
- 蓝鲸手账布局：鲸形番茄钟、角色贴纸、鲸鱼航线、深蓝记录卡和梁文锋照片与小鲸同人拼贴。手机上小鲸位于番茄钟之前，首屏即可看到。
- 鲸鱼娘支持待机、看书、休息、轻触回应、悬停跟随和思考动画；尊重系统与网页的减少动效设置。
- 数据保存在当前浏览器，导入导出在本机完成。
- 小鲸支持可配置的 AI 聊天与计划分析；未配置接口时提供本地统计建议。

## 本地预览

项目是原生 HTML、CSS 和 JavaScript ES 模块，无第三方运行依赖，也不需要安装 npm 包。

电脑安装 Python 3 后，Windows 用户可以双击项目根目录中的 `start-preview.cmd`。它会在当前项目目录启动本地预览服务器，并打开默认浏览器；关闭服务器窗口或按 `Ctrl+C` 即停止预览。

也可以在项目目录的终端运行：

```powershell
python -m http.server 4173 --bind 127.0.0.1
```

然后打开 [本地预览](http://127.0.0.1:4173/)。

请通过本地 HTTP 地址预览。直接双击 `index.html` 的 `file://` 打开方式可能受到 ES 模块和浏览器存储规则限制。为了持续使用同一份本地数据，请固定使用同一浏览器和地址（包括端口）。[浏览器本地存储说明](https://developer.mozilla.org/en-US/docs/Web/API/Window/localStorage)

## 任务与计时规则

任务名称可以直接选为当前任务；任务的更多操作中可以添加子任务、调整父级、移动顺序和只看该项。每个任务的完成状态独立，勾选或取消只影响当前任务，主任务需要手动确认；父级汇总后代的时间和番茄时不会重复计数，可在任务编辑窗口中查看汇总。

完整完成一轮专注才记为一个番茄。暂停、重置或切换模式不增加完成番茄数，暂停前实际投入的时间仍计入专注时间。休息时间不计入专注时长，日期按设备本地时间划分。

刷新或重新打开时按实际剩余时间恢复。如果原来的一轮已经到期，只结算这一轮并等待继续，不会补算离线期间的后续轮次。网页保持打开时提供到点提醒；锁屏、系统休眠和浏览器后台限制可能影响声音或桌面通知。

## 本地数据与备份

本版本没有注册或登录。不同设备、不同浏览器和不同网站地址各自保存数据，不会自动跨设备同步。清除网站数据、使用会被自动清理的浏览模式，或者更换浏览器前，建议先导出备份。

点击页面顶部的备份按钮：

1. 选择“导出 JSON”，下载一份完整备份，包含任务父子关系、任务状态、专注记录、设置和本轮计时进度。
2. 在另一设备或浏览器选择备份文件。网页先检查结构、任务关系和记录内容。
3. 选择“合并到现有数据”或“替换当前数据”，再确认导入。

“合并”保留本机的设置和当前计时进度，并暂停本轮，合并任务并去重记录；“替换”使用备份中的任务、记录和设置，计时以暂停或空闲状态恢复，避免导入后意外自动开始。替换前请先导出本机备份。

备份文件只在你的浏览器内读取，不上传到 GitHub 或其他服务器。导出文件包含任务文字和历史记录，请自行保管。删除任务会移除任务子树，历史记录仍保留当时的任务名称。

### 方式一：从分支发布（最简单）

1. 登录自己的 GitHub 账号，新建公开仓库 `whale-pomodoro`。
2. 将项目文件上传到仓库根目录。请确认根目录可以直接看到 `index.html`，而不是再套一层 `whale-pomodoro/` 文件夹。
3. 确认 `styles.css`、`design.css`、`app.js`、`companion.js`、`mini-timer.js`、`model.js`、`timer.js`、`ai.js`、`ai-ui.js`、`.nojekyll` 和 `assets/` 都在仓库中。

无需修改用户名到网页代码里；页面使用相对路径，适用于项目子目录地址。[从分支发布的官方步骤](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)

### 方式二：GitHub Actions 自动部署

源码包附带 `.github/workflows/pages.yml`。通过 Git 上传时保留这个隐藏目录，然后将 **Settings → Pages → Source** 改为 **GitHub Actions**。推送到 `main` 或在 Actions 中手动运行该工作流即可发布。

这个工作流会整理静态文件并上传，运行时不需要服务器进程，也不需要 npm 安装或构建步骤。分支发布和 Actions 发布二选一即可。[自定义 Pages 工作流官方说明](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages)

## 小鲸 AI 聊天与计划分析

点击角色下方的“配置接口”，选择 DeepSeek 后粘贴官方密钥，点击“读取可用模型”，从平台返回的下拉列表中选择模型，再点击“保存并测试”。测试成功会直接保存配置，关闭窗口即可使用。模型 ID 也可以手动修改；兼容接口的基础地址或完整请求地址放在“高级设置”中。选择预设不会清空已经填写的密钥。[DeepSeek 接口文档](https://api-docs.deepseek.com/)

- **分析计划**：选择全部任务或当前任务的子树，查看预计总番茄数、实际完整番茄数和实际专注分钟。根据已完成且有预算的独立任务计算用时比例；样本不足三项时会说明不足。未完成任务不会仅因已用时间少就被判断为更快。
- **AI 建议**：配置接口并允许发送统计后，分析会把任务与专注统计发送到你填写的地址。可以填写本次调整目标，并给出“接下来这样做”的具体步骤、预算调整和新子任务；每条建议还有对应当前界面按钮的手动修改指南。勾选要接受的建议后点击“应用所选建议”才会写入。不会删除、移动、勾选任务或改变当前计时。分析后若修改过任务，需重新分析。
- **聊天与气泡**：在小鲸旁边直接输入，或点击“和小鲸聊天”展开对话。轻点角色或“换一句”会根据最近对话生成一条新回应，结果持续保留在气泡中。展开对话可以看到完整回复。聊天可选择附带任务统计，默认只发送输入及最近六轮对话；点击换句最多携带最近六条消息。加载、悬停和计时切换不会自动请求接口。聊天不会直接修改任务。
- **未配置接口**：计划分析仍可使用本地统计，聊天会提示配置，不会生成假 AI 回复。

密钥默认仅保留在页面内存；可主动选择在当前标签页的会话存储中暂存，以便刷新后继续使用。接口地址、模型与发送统计选项保存在当前浏览器；密钥、接口配置和聊天不进入任务备份。密钥不会写进公开源码，每位访客使用自己的密钥。聊天只在当前页面保留，刷新后清空；服务商如何保存请求由该服务商规则决定。调用可能产生费用。

GitHub Pages 提供静态网页，浏览器直接请求你配置的接口；服务商必须允许浏览器跨域访问。不支持时可填写自己部署的代理地址。DeepSeek 的“保存并测试”会先读取真实模型，再发送一句短测试文字；读取模型不生成聊天内容。当前 DeepSeek Flash / Pro 默认使用非思考模式，避免短测试耗尽思考预算。接口请求遇到无效密钥、余额不足、无效模型、限流、超时或格式错误会显示 HTTP 状态、服务商说明与错误代码（密钥内容会隐藏），不会自动修改计划。AI 每次最多接收分析范围内 200 项任务（优先未完成），更多任务可以按子树分别分析。

历史预算采用“当前一轮专注时长”折算比较，历史上更改过轮长、任务难度差异、未记录的工作都会影响判断。建议用于安排余量，并非对能力的评判。旧版已经自动勾选的父任务会保留原状态，可手动取消一次；新版不再自动联动。

## 桌面悬浮倒计时（v1.2.1）

在支持 Document Picture-in-Picture 的桌面浏览器中（例如支持该功能的 Chrome / Edge），点击开始或继续计时，会按“开始时打开”选项自动打开置顶小窗。也可点击番茄钟下方的“桌面小窗”手动打开。小窗内容只有剩余时间，没有角色、任务和操作按钮；暂停和继续请在主页面操作。默认请求 200×90 像素，实际最小尺寸与浏览器自带的关闭栏由浏览器决定。拖动小窗标题区域可移动，拖动边缘或角可调整大小，数字会随窗口缩放。浏览器通常会记住上次的窗口位置与大小。

小窗与主页面使用同一计时状态，关闭小窗不会暂停计时或增加记录。完成一轮时同步显示下一阶段；主页面刷新或关闭时，桌面小窗随之关闭，不会自行重新弹出。取消“开始时打开”后保留手动入口；此偏好保存在当前浏览器，独立于任务备份。不支持的浏览器会显示说明，计时仍可正常使用。打开失败或超时后可点击重试。

该功能需要 HTTPS（本站 GitHub Pages 已使用）或本机 localhost，并由用户点击触发，不会在加载网页时自行弹出。

参考：[Chrome 官方 Document Picture-in-Picture 说明](https://developer.chrome.com/docs/web-platform/document-picture-in-picture)、[MDN requestWindow](https://developer.mozilla.org/en-US/docs/Web/API/DocumentPictureInPicture/requestWindow)。
